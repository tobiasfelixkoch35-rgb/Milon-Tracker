MILON TRACKER 1.0

Dateien auf einen HTTPS-Webhost hochladen (z.B. GitHub Pages oder Netlify).
Die index.html im Android-Chrome öffnen, Menü > Zum Startbildschirm hinzufügen / App installieren.
Nach dem ersten vollständigen Laden funktioniert die App offline.
Daten bleiben lokal im Browser (localStorage). Regelmäßig im Setup JSON-Backup exportieren.

Lokaler Test am Computer: Im entpackten Ordner `python -m http.server 8000` ausführen und http://localhost:8000 öffnen.

Hinweis: Dies ist eine erste Version. Vor produktivem Einsatz Backup- und Restore-Ablauf testen.
